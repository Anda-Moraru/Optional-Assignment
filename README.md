# Optional Assignment


This project implements two deep learning models that transform RGB images of size 3×32×32 into grayscale images of size 1×28×28, with horizontal and vertical flips applied. Both models are trained on the CIFAR-10 dataset. Model 1 is optimized for inference speed, achieving faster performance than sequential CPU transformations, while Model 2 prioritizes prediction quality, achieving significantly lower training and validation losses with predictions very close to the ground truth.

## Project Structure

## Models

### Model 1: 

Model 1 uses a simple convolutional architecture optimized for speed:
- 4 convolutional layers with ReLU activations
- Downsampling via stride=2 in the second layer
- Dilated convolutions to increase receptive field
- Final 1×1 convolution for RGB to grayscale conversion
- Nearest neighbor interpolation for resizing from 16×16 to 28×28
- The model learns the complete transformation, including horizontal and vertical flips

 The simple architecture allows fast training on CPU and efficient inference. The model learns the complete RGB to grayscale transformation, resizing, and flips end-to-end, enabling true end-to-end learning of the entire transformation.

**Training Results**:
- Epoch 1: Training loss = 0.149933, Validation loss = 0.132575
- Epoch 80: Training loss = 0.122436, Validation loss = 0.122933

**Performance**: Model 1 achieves faster inference than sequential CPU transforms starting from batch size 16 on CPU, and from batch size 8 on CUDA.

### Model 2: 

Model 2 uses a U-Net inspired encoder-decoder architecture optimized for quality:
- Encoder with two downsampling blocks and a bottleneck
- Decoder with skip connections to preserve fine details
- Each block uses dilated convolutions for increased receptive field
- Final 1×1 convolution for RGB to grayscale conversion
- Nearest neighbor interpolation for final resizing
- The model learns the complete transformation, including horizontal and vertical flips

 The architecture with skip connections preserves fine-grained details from the input, crucial for accurate image transformation. The hierarchical structure captures features at different scales, allowing the model to learn both local and global patterns.

**Training Results**:
- Epoch 1: Training loss = 0.159972, Validation loss = 0.119318
- Epoch 80: Training loss = 0.027211, Validation loss = 0.026560

**Performance**: Model 2 achieves excellent prediction quality but is slower than sequential transforms on CPU. On CUDA, it becomes faster than sequential transforms starting from batch size 8 .

## Loss Function

**L1Loss (Mean Absolute Error)** - Used for both models because:
- It is robust to outliers compared to MSE
- Produces smoother results for images
- Is suitable for pixel-wise regression
- Provides stable gradients during training

## Early Stopping

- **Patience**: 7 epochs
- **Min Delta**: 1e-4
-  Prevents overfitting and stops training when the model no longer improves on the validation set. A patience of 7 epochs provides a balance between training time and the possibility of improvement.

To run the inference benchmark for both models:

TensorBoard logs for both models are available in `runs/model/` and can be visualized with:

The logs include training and validation loss curves for both models, allowing for comparison of their training dynamics.
